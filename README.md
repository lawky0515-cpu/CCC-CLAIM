# 公司 Claim 记录

纯 HTML、CSS、JavaScript 网站，无需安装依赖或构建。

## 本地使用

双击 `start.cmd`，保持服务窗口运行，然后打开 http://127.0.0.1:8765 。直接打开 index.html 无法自动写入文件夹。

## GitHub Pages

1. 把此文件夹内的 `index.html`、`style.css`、`app.js` 和 `.nojekyll` 上传到 GitHub 仓库根目录。
2. 在仓库 Settings → Pages 中，选择 Deploy from a branch。
3. 选择 main 分支与 / (root)，保存。

手机端读取使用 Apps Script 的 GET 通道。更新 `google-apps-script/Code.gs` 后，必须在 Apps Script 的“管理部署”中编辑现有部署并选择“新版本”，否则 `/exec` 仍会运行旧代码。

支持新增、编辑、删除 Claim，按状态筛选，以及金额汇总。金额默认 RM，精确到分。状态仅包括未支付、已支付。旧记录中的待审核、已批准和已拒绝会自动显示为未支付，并在下一次保存记录时写入存储。

Evidence 凭证支持 JPG、PNG、WebP 和 PDF，每笔最多 3 个文件，总大小不超过 2 MB。选择文件后点击添加记录或保存修改，才能保存凭证。表格中的文件名可打开预览并下载；编辑记录时可移除或替换凭证。浏览器总存储容量有限，空间不足时会提示保存失败并保留表单内容。凭证同样仅保存在本机，不会上传到 GitHub。

进入成员页面、重新切回网页及页面保持开启期间每 60 秒，都会自动从 Google Sheets 读取所有成员的最新记录。新增或编辑时，网站先写入 Google Sheets，成功后立即重新读取整张表并刷新页面；删除也会同步到云端。浏览器的 localStorage 同时保留本机副本。同步失败时本机新增或编辑内容仍会保留，并可使用页面上的“刷新云端记录”重试。

成员包括 BOSS L、BOSS W、BOSS K。新增记录时必须选择成员，支持成员和状态组合筛选；顶部汇总统计所选成员的全部状态，表格合计统计筛选结果。旧记录显示为未指定成员，可编辑后分配成员，已有凭证保留。

## 自动保存凭证

通过本地服务上传后，真实文件立即写入本项目 evidence 文件夹，无需文件夹选择器。随机文件名避免覆盖。还需保存 Claim 以关联记录；取消或删除 Claim 不删除磁盘副本。浏览器仍保留预览副本和原有容量限制。

GitHub Pages 会把凭证直接上传到 Google Drive。本地服务还会额外保存一份凭证到电脑的 evidence 文件夹。file://、本地服务和 GitHub Pages 使用不同的浏览器存储，旧记录不会自动迁移。

## 成员进入页面

打开网站先选择成员，新增 Claim 自动归属当前成员。刷新当前标签页会保留身份，右上角可切换成员。进入后默认显示全部成员、全部状态的记录；编辑其他成员记录时保留原成员。这是本机身份选择，不是安全登录或访问权限控制。
